Regular Expression Denial of Service (ReDoS)

OWASP: A05:2021 - Security Misconfiguration CWE-1333

1. What is it?

ReDoS (Regular Expression Denial of Service) happens when crafted input forces a vulnerable regular expression to test millions of pattern combinations. This traps the browser's main thread in heavy processing, maxing out CPU usage and freezing the web page.

2. Why it matters?

A single malicious input can max out CPU usage to freeze a user's browser tab or crash an entire application without needing a botnet. For example, in 2019, a single flawed regular expression caused a massive outage at Cloudflare that knocked millions of websites offline for 27 minutes.
