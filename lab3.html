JacaScript Prototype ↗ Prototype Pollution ↗

1. What is it?

Client-side prototype pollution is a JavaScript vulnerability where an attacker modifies an object's prototype (usually Object.prototype) through unsafe handling of user-controlled input.

2. Why it matters?

In 2020, a vulnerability reported on HackerOne demonstrated how prototype pollution could be exploited to achieve XSS, allowing attackers to execute malicious JavaScript in a user's browser.
