DOM-Based Open Redirect

OWASP A01:2021 — Broken Access Control ↗ CWE-601 ↗

1. What is it?

A DOM-based open redirect occurs when JavaScript reads an attacker-controlled URL parameter and uses it as a navigation destination without validation. A trusted-looking link can then send a visitor to an unrelated website.

2. Why it matters?

Attackers can disguise phishing destinations behind a familiar domain, increasing the chance that users trust the link. The weakness is classified as CWE-601: URL Redirection to Untrusted Site.
